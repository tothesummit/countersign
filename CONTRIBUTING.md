# Contributing

Countersign is in design phase. The most useful contribution right now is an issue that shows how the two-channel rule, the risk gate or any of the [release invariants](SECURITY.md#invariants) could be bypassed. Security problems go through private vulnerability reporting, not a public issue — see [SECURITY.md](SECURITY.md).

## Pull requests

Open an issue before starting anything large, so the design can be agreed first.
